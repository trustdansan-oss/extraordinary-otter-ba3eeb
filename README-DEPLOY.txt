FAST Tracking Website — Netlify upload

Upload this ZIP to Netlify Drop (manual deploy). The website files are at the ZIP root and index.html is the home page.

For direct email sending, keep the Netlify environment variables GMAIL_USER and GMAIL_APP_PASSWORD set for Production, then redeploy. Never put passwords in this ZIP.

Latest correction: tracking dashboard now uses full available width, shipment note appears below tracking code, map/vehicle/location sections are moved higher, and email copy button opens a dedicated copy-code page because email apps block JavaScript clipboard actions.
